# WhipKlean

WhipKlean is a mobile vehicle-detailing website for customers across its
Canadian service area. The site presents wash and deep-cleaning services,
explains mobile appointment requirements, collects quote requests, and provides
a fillable service agreement.

## Local development

Requirements: Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```
